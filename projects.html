Featured Work · Interactive Web Experience

Lineage: a family documentary, hand-built and animated in the browser.

A self-contained interactive documentary that traces five ancestral lines across four countries, from 1604 to the present day. The page renders an animated SVG family tree synchronized to a 50-minute narration track, with a moving year axis, world-event markers, and Leaflet map insets that surface on migration beats. Built in vanilla JavaScript with no framework and no build step: one page that loads its own timeline data, caption engine, and audio cueing. Opens in a new tab.

Featured Work · Microsoft 365 Agent Delivery

Copilot Concierge: a production M365 triage agent built on Copilot Studio, Azure AI Foundry, and Claude.

A scoped, shippable agent that triages inbound Outlook messages against a six-category classifier, drafts replies in the user's voice, and writes every decision to an audit log. Built on Copilot Studio fronting Azure AI Foundry, with Claude Sonnet via Foundry handling classification and drafting, Microsoft Graph for inbox, calendar, Teams, and Planner context, and Application Insights for the audit trail. The case study covers the tool catalog, the classifier, the voice profile, the data model, and the security posture. A technical appendix documents the Graph scopes, typed tool signatures, Dataverse schema, and Kusto audit queries.
